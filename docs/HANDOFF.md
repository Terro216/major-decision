## Что исправлено

- Убран скачок ускорения на входе и выходе трубы. Две плавные рампы скорости
  соединены равномерным проходом; сохранены все времена и скорости на торцах.
  Пиковая скорость 134.00 / 152.32 уменьшилась до 114.60 / 129.94.
- Прямые горловины и спираль соединены C2-осью, общей для стенки и шара.
  До изгиба остаётся .60 прямого участка, больше полного радиуса .58.
  Касательные сечений Three.js используют тот же параметр, что и их центры.
- Слайдер и экспорт больше не округляют 24 fps до сотых секунды.
  Chromium получает i/24 с точностью 12 десятичных знаков; все 167 значений
  отдельно проверены, максимальная ошибка меньше 3.34×10⁻¹³ s.
- Усилены проверки ускорения, кривизны, полного прохода через торцы,
  дробной перемотки и покрытия промежутков новой оси.
- Исправлен EXIT-handler экспортера: отсутствие необязательного каталога
  больше не превращает успешно законченный экспорт в exit 1.

Радиус шара **.58**, канал **.70**, стенка **.78**, 34 штыря и 8 касаний
на каждый маршрут сохранены. Прозрачность и постановочные ключи камеры
не изменены. На части спирали камера, как и прежде, вычисляется от положения
шара, поэтому новый профиль влияет на её промежуточные координаты.

Вход **4.30 / 4.40**, выход **4.91 / 4.94**, удар **5.80**, финал **6.90 s**.
LEFT/RIGHT и ответ выбираются независимо и по одному разу. Названия yes/no

## Повторение и уборка

Сначала проверить `command -v node npm docker`: это SSH-shims на big-one.
Git и файлы локальные. После автоматической синхронизации сверить SHA
нужных файлов на обоих хостах. Не выполнять общий flush дерева server
для этой задачи: он не нужен для адресной сверки проекта.

Сначала выполнить:

```sh
python3 scripts/check-references.py
bash scripts/check-remote.sh
```

Вторая команда запускает один worker в контейнере
2 CPU / 1536 MiB. Только после успеха новая сборка попадает в `.review/dist`.
Для экспорта запустить в отдельном терминале preview на
`127.0.0.1:4175` на big-one:

```sh
node --max-old-space-size=256 node_modules/vite/bin/vite.js preview --outDir .review/dist --host 127.0.0.1 --port 4175 --strictPort
```

Затем, последовательно, без дубликатов браузерных контейнеров:

```sh
node scripts/check-preview.mjs
bash scripts/export-review.sh
# На big-one:
python3 scripts/prepare-motion-review.py after
bash scripts/export-review.sh --cross
# На big-one:
python3 scripts/prepare-motion-review.py cross
python3 scripts/prepare-motion-review.py comparisons
bash scripts/check-review-media.sh
bash scripts/check-randomness.sh
```

После **фактического** просмотра всех кадров и сравнений записать
visual-review.json. Локально выполнить
`python3 scripts/verify-motion-review.py --collect`, затем обычный запуск
без `--collect` для проверки сохранённого набора. Перед уборкой сверить
его и на big-one. Остановить только использованный проверочный preview,
удалить только созданную этим проходом `.review`, проверить отсутствие
контейнеров и повторить проверку компактного набора без рабочей директории.

Если SSH завершился раньше контейнера, сначала прочитать удалённый журнал
и проверить его фактическое завершение; не запускать дубликат. Фаза `before`
нового генератора защищена от перезаписи архива 20 октября. Для следующего
изменения сначала сохранить отдельную датированную исходную версию.
