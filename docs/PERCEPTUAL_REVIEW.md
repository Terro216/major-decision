# Perceptual comparison

The reconstruction retains the film's composition and visual language. Remaining
approximation includes glass highlights, mouth rims, ball texture, letter bevels
and icon details. Monitor curvature, grain and scan artifacts are not reproduced.

Accepted usability choices are a clear interface and the complete lower oval.
Assess animation at normal speed and inspect transitions with seeking. Deterministic
video export is useful for comparisons but is not a device frame-rate measurement.
User acceptance must be recorded separately from automated test results.
