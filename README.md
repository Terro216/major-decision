# Major Decision

Реконструкция машины решений из фильма «Трасса 60» (Interstate 60).
Задайте вопрос, нажмите `?` и наблюдайте, как оранжевый шар проходит через
цветные штыри и спираль к ответу **YES** или **NO**.

**[Открыть сайт](https://decision.ilyamedve.dev)**

## Возможности

- **Movie** — две постановочные траектории по мотивам фильма.
- **Freestyle** — новый путь шара с расчётом столкновений при каждом запуске.
- Оба режима используют живую 3D-сцену; ответ выбирается случайно,
  независимо от маршрута.
- Русские и английские вопросы, мобильная компоновка, управление с клавиатуры.
- Звук по желанию, пауза и пропуск анимации, поддержка reduced motion.
- Если WebGL недоступен, выбранный ответ отображается без 3D-анимации.

HOROSCOPE, ROMANCE и CAREER сохранены как детали интерфейса из фильма
и неактивны.

## Как пользоваться

Введите вопрос и нажмите `?` или Enter. Shift+Enter добавляет новую строку,
а `NEW QUESTION` сбрасывает ответ и очищает поле.

По умолчанию случайный ответ выбирается в браузере через WebCrypto.
Можно включить RANDOM.ORG: сервис получает запрос случайных чисел,
без текста вопроса. Если сервис недоступен, приложение сообщает об ошибке.

Аккаунт не нужен. Вопрос остаётся в памяти вкладки и не сохраняется.
Аналитика посещений не получает текст вопроса, ответ или параметры URL.

## Разработка

Стек: React, TypeScript, Vite и Three.js. Для запуска нужен Node.js 22.12
или новее.

```sh
npm ci
npm run dev
```

Откройте адрес, который Vite покажет в терминале.

```sh
npm run build    # Проверка TypeScript и сборка в dist/
npm run preview  # Просмотр собранной версии
```

Материалы фильма не включены в репозиторий и не нужны для запуска.
Шрифты поставляются вместе с лицензиями в `public/fonts/`.
