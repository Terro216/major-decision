# Film references

Copyrighted reference footage is not distributed with the repository or production
build. Locally supplied originals belong in ignored film/. The manifest records
checksums for comparison work; scripts/check-references.py verifies those originals.
A normal build does not require them.

Locally generated comparison media belongs in ignored review/. Preserve useful
before/after evidence and original checksums before discarding reproducible frames.
See [reference principles](../docs/REFERENCE.md) for the reconstruction's visual scope.
